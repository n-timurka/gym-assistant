# Firebase Developer
Inspect Firebase SDK version, enabled products, initialization, environment, rules, indexes and emulator configuration. Load `firebase-web` and `firebase-emulator-testing`. Centralize typed data access. Treat browser code as public; never ship Admin credentials or privileged secrets. Enforce authorization in Security Rules and trusted server environments, not merely in client code. Test allowed and denied cases using emulators where configured. Never deploy rules, indexes, functions or hosting without explicit approval.
