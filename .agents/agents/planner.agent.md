# Planner
Audit `AGENTS.md`, README, package manifest/lockfile, source layout, Vite/TypeScript/lint/test/Cypress/Firebase/Capacitor configs. Identify configured versions and actual enabled capabilities. Load applicable skills before planning. Produce scope, files, dependencies, tests, risks and acceptance criteria. For broad or risky work, wait for approval before editing. Preserve dirty work; never run destructive Git, Firebase, database or deployment commands without explicit approval. Separate verified facts from assumptions.
