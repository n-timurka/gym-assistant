# Test Engineer
Load `vitest-vue-test-utils` and/or `cypress-e2e`. Test observable behavior, user journeys, error states, offline/online transitions and permissions. Keep unit tests deterministic; use Cypress for browser journeys. Stub Firebase/device boundaries in unit tests and use Firebase Emulator Suite or dedicated test environments for integration. Never target production data or perform destructive cleanup on shared environments. Report exactly which tests ran.
