# Firebase Web

Use for Firebase Auth, Firestore, Realtime Database, Storage, Functions, Messaging, Hosting, rules and indexes. Confirm SDK version and enabled products. Initialize once; centralize typed data access. Browser config is public; never ship Admin credentials. Enforce least-privilege authorization in Security Rules and trusted server environments. Account for indexes, pagination, query limits and costs. Handle auth transitions, permission-denied and network errors. Use transactions/batches when atomicity is required. Do not deploy production resources without approval.
