# Ionic and PWA Testing

Use for hybrid/PWA validation. Separate browser checks from native plugin checks. Validate offline startup, reconnect, stale-cache recovery, permissions denied, unavailable APIs, lifecycle and network transitions. Test native camera/filesystem/push/geolocation on devices or simulators. Record platform, OS/browser and plugin versions for device-specific failures.
