# Linting and Code Quality

Use for ESLint/Prettier/Stylelint/TypeScript quality gates. Inspect installed tools and versions before changing config. Preserve current config format and avoid unrelated formatting churn. Keep lint, format-check and typecheck distinct. Do not weaken rules just to pass. Scope suppressions narrowly and explain them. Run exact package scripts and report results.
