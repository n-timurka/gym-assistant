# Vite PWA

Use for manifest, service worker, offline behavior, installability and caching. Inspect the existing plugin/strategy. Configure manifest metadata and icons consistently. Cache only safe resources; avoid indiscriminate caching of authenticated responses or sensitive data. Define runtime caching by resource type, expiry and versioning. Test first install, repeat visit, offline launch, reconnect, update and cache invalidation. Provide deliberate update UX and account for platform/browser differences.
