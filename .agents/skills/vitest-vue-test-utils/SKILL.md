# Vitest + Vue Test Utils

Use for unit/component tests. Follow existing config and setup. Mount components and assert observable behavior using accessible roles, labels, text or stable test IDs. Test emitted events, interactions, validation and loading/error states. Mock Firebase/device boundaries at service seams. Reset mocks, timers and global state. Use async utilities rather than fixed sleeps. Avoid snapshot-only coverage and assertions against private implementation details.
