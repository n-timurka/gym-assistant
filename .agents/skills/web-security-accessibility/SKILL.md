# Web Security and Accessibility

Use for auth, forms, data views and user interactions. Treat input, URL params, storage and remote data as untrusted. Prevent XSS; avoid unsafe HTML. Never expose secrets in frontend code/storage. Client route guards are not authorization. Minimize sensitive data in logs and caches. Use semantic HTML, labels, keyboard support, visible focus, contrast, reduced motion, announced status changes and focus management for dialogs/errors.
